# NinaPeps BioLab — Version 2

This version uses the uploaded laboratory vial image as the hero visual and combines it with a pink, aqua, and lavender biotech identity.

## Included
- Responsive homepage
- NinaPeps BioLab branding
- Uploaded vial hero image
- Pink/aqua/lavender research catalog placeholders
- Product filtering
- Standards, About, FAQ, Contact sections
- Research-use-only language

## Safety / content positioning
This version intentionally does not include:
- checkout or purchase buttons
- dosing or injection instructions
- treatment / weight-loss / medical claims
- regulated prescription products as direct-sale listings

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/lab-vial.webp`
